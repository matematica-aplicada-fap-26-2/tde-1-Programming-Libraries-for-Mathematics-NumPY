# Programação Aplicada à Matemática — NumPy

Este repositório foi criado para o desenvolvimento de um trabalho acadêmico da disciplina de **Matemática Aplicada à Computação**.

O projeto tem como objetivo reunir explicações e exemplos práticos de utilização da biblioteca **NumPy** em Python, demonstrando sua aplicação em operações e problemas matemáticos.

Ao longo do trabalho, o repositório será atualizado com códigos, exercícios e materiais produzidos pela equipe, servindo tanto como registro do desenvolvimento do projeto quanto como apoio para sua apresentação.

## Contexto acadêmico

- **Disciplina:** Matemática Aplicada à Computação
- **Tema:** Bibliotecas de programação para matemática
- **Biblioteca escolhida:** NumPy
- **Finalidade:** Trabalho acadêmico
