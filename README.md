# Programação Aplicada à Matemática — NumPy

Este repositório foi criado para o desenvolvimento de um trabalho acadêmico da disciplina de **Matemática Aplicada à Computação**.

O projeto tem como objetivo reunir explicações e exemplos práticos de utilização da biblioteca **NumPy** em Python, demonstrando sua aplicação em operações e problemas matemáticos.

Ao longo do trabalho, o repositório será atualizado com códigos, exercícios e materiais produzidos pela equipe, servindo tanto como registro do desenvolvimento do projeto quanto como apoio para sua apresentação.

## Exemplos de código

Os exemplos usados na apresentação estão separados na pasta `exemplos/`. Cada arquivo possui comentários explicando as operações realizadas.

Para instalar a biblioteca necessária, execute:

```bash
pip install -r requirements.txt
```

Depois, execute qualquer exemplo a partir da raiz do repositório:

```bash
python3 exemplos/01_manipulacao_arrays.py
```

Arquivos disponíveis:

- `exemplos/01_manipulacao_arrays.py`: criação, alteração, adição, remoção e ordenação de arrays;
- `exemplos/02_operacoes_matematicas.py`: soma, média, máximo, mínimo, vetorização e raiz quadrada;
- `exemplos/03_ndarray_matriz.py`: matriz, indexação, dimensões e formato;
- `exemplos/04_estatistica.py`: média, mediana e desvio padrão.
